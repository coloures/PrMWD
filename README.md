# Лабораторная работа №3: Продвинутые модели ML и интерпретация

## Цель
Освоить продвинутые модели машинного обучения (градиентный бустинг, ансамбли), научиться
оптимизировать гиперпараметры (Optuna), интерпретировать модели (SHAP) и работать с
несбалансированными классами.

## Вариант и данные
- **Вариант №1** — **Titanic** (`seaborn`), бинарная классификация (таргет `survived`).
- Ноутбук: `src/notebooks/laboratory_3.ipynb` (выполнен: все таблицы, графики и выводы внутри).
- Данные: `src/data/raw/titanic.csv` — тот же файл, что и в ЛР1–ЛР2, под DVC (повторно из сети не
  выгружается). 891 строка × 15 колонок, доля выживших 0.384 (лёгкий дисбаланс 38/62);
  пропуски: `age` 252, `fare` 89, `embarked` 2, `deck` 688.

## Что реализовано (по шагам задания)

| Шаг | Реализация |
|---|---|
| Предобработка | `TitanicFeatureAdder` (`family_size`, `is_alone`, `fare_per_person`, `sex_class`, `deck=Unknown`) + `ColumnTransformer`: медианная импутация + `StandardScaler` для числовых, мода + One-Hot для категориальных |
| Базовые бустинги | XGBoost, LightGBM, CatBoost с параметрами по умолчанию, `StratifiedKFold(5)`, метрика ROC-AUC + замер времени |
| Оптимизация | Optuna (TPE, `seed=42`), **60 trials** (≥50 по заданию), CV внутри objective; обязательные `learning_rate`/`depth`/`iterations` (+ `l2_leaf_reg`, `subsample`) |
| Интерпретация | SHAP `TreeExplainer`: `summary`, `bar`, `dependence` (2 важнейших признака), `waterfall` (3 объекта) |
| Стекинг | `StackingClassifier` (**LightGBM + RandomForest + LogisticRegression**), `cv=5`, `stack_method='predict_proba'` |
| Дисбаланс | **Взвешивание классов** (`auto_class_weights='Balanced'` для CatBoost) и **SMOTE** внутри `imblearn.pipeline.Pipeline` (ресемплинг только на train-фолдах); метрики PR-AUC и F1 |
| Финальная оценка | Отложенный тест 25% (223 объекта), сводная таблица CV + TEST |

## Результаты

### Базовые бустинги (5-fold CV, ROC-AUC)
| Библиотека | ROC-AUC (5-fold CV) | CV 5 фолдов, с |
|---|---|---|
| **CatBoost** | **0.8688 ± 0.0158** | 10.05 |
| LightGBM | 0.8403 ± 0.0204 | 0.67 |
| XGBoost | 0.8309 ± 0.0228 | 1.16 |

Выбрана **CatBoost**: «из коробки» лучше LightGBM на +0.029 и XGBoost на +0.038 ROC-AUC (больше
одного `std` — устойчивый выигрыш), при приемлемом для 891 строки времени.

### Оптимизация гиперпараметров (Optuna, 60 trials)
Лучшая конфигурация: `learning_rate=0.134`, `iterations=100`, `depth=2`, `l2_leaf_reg=8.86`,
`subsample=0.746` → **ROC-AUC 0.8840 ± 0.0173** (**+0.0152** над CatBoost по умолчанию). Оптимум
сместился к мелким деревьям (`depth=2`) и сильной L2-регуляризации — признак того, что глубокая
дефолтная модель переобучается на маленьком датасете.

### Стекинг vs лучшая одиночная модель (5-fold CV)
| Модель | ROC-AUC |
|---|---|
| **Оптимизированный CatBoost** | **0.8840 ± 0.0173** |
| Стекинг LightGBM+RF+LogReg | 0.8666 ± 0.0123 |

Стекинг на **0.0174 хуже**: на малом датасете мета-комбинация ненастроенных базовых моделей не
добавляет информации к сильному бустингу.

### Несбалансированные классы (5-fold CV)
| Подход | PR-AUC | F1 | ROC-AUC |
|---|---|---|---|
| Базовая (без учёта дисбаланса) | **0.8536** | 0.7531 | 0.8816 |
| Взвешивание классов | 0.8512 | 0.7595 | 0.8795 |
| SMOTE | 0.8422 | **0.7615** | 0.8718 |

### Финальная оценка на отложенном тесте (223 объекта)
| Модель | ROC-AUC | PR-AUC | F1 | Accuracy |
|---|---|---|---|---|
| Оптимизированный CatBoost | 0.8397 | 0.7988 | 0.7152 | 0.7892 |
| Стекинг (LightGBM+RF+LogReg) | 0.8348 | 0.8086 | 0.7000 | 0.7848 |
| Взвешивание классов | 0.8398 | 0.7903 | 0.7391 | 0.7848 |
| SMOTE | 0.8437 | 0.7942 | 0.7200 | 0.7803 |

## Выводы
1. **Оптимизация гиперпараметров (Optuna)** — единственный значимый на CV прирост (**+0.0152**).
2. Правильный **выбор библиотеки** (CatBoost вместо дефолтных XGBoost/LightGBM) — +0.038/+0.029.
3. **Стекинг** и **обработка дисбаланса** при лёгком дисбалансе (38/62) прироста не дают (в пределах
   статистического шума): взвешивание и SMOTE повышают только F1, слегка ухудшая ранжирование.
4. Самые важные признаки по SHAP: **`adult_male`** (0.999), далее `sex_class` (0.301), `deck` (0.281),
   `fare_per_person` (0.267), `age` (0.203) — согласуется с историей Titanic («женщины и дети —
   первыми» плюс цена и класс каюты).
5. Разница между финальными кандидатами на тесте лежит в пределах шума (223 объекта), поэтому
   «победителя» определяет кросс-валидация.
